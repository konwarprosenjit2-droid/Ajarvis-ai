# JARVIS AI — Prosenjit (Demo)

A static, mobile-friendly JARVIS-style chat website. Replies are simulated with pre-written responses; this is not connected to a real AI model and needs no API key.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Extract this ZIP.
2. Create a new GitHub repository and upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In Vercel, choose **Add New → Project**, import that repository, and deploy.
4. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (root).
5. After deployment, open the generated `vercel.app` URL.

No secrets or API keys are required.
